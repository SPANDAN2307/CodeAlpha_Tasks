# 🚀 CodeAlpha Internship Tasks
**Author:** Spandan

Welcome to the central repository for all tasks completed during my **CodeAlpha Internship**. This repository strictly isolates Frontend and Backend development tasks into a decoupled architecture, demonstrating progressively complex, professional-grade development paradigms.

---

## 📂 Repository Architecture

The project tracks are divided securely into two primary directories. Each internal project comes equipped with its own documentation, decoupled configuration boundaries, and decentralized package `.gitignore` trackers. 

### 🎨 Frontend Development Tasks
Focused heavily on user experiences using pure Vanilla web-technology stacks (`HTML5`, `CSS3`, `Vanilla JS(ES6)`) focusing on modern techniques like Masonry design schemes, dynamic glassmorphism engines, and `localStorage` algorithms.

* **Task 1: [Smart Calculator](./CodeAlpha_Frontend_Development_Tasks/CodeAlpha_Calculator)** — A responsive arithmetic tool featuring functional keyboard bindings and complex string parsing.
* **Task 2: [Bommbash Music Dashboard](./CodeAlpha_Frontend_Development_Tasks/CodeAlpha_Music_Player)** — A highly animated, Apple Music-inspired web media interface that parses online radio endpoints and integrates high-fidelity UI trackers.
* **Task 3: [Dynamic Image Gallery](./CodeAlpha_Frontend_Development_Tasks/Image_Gallery)** — A Pinterest-style modular grid system employing client-sided blob upload routing, modal rendering, and sophisticated dark mode caching.

### ⚙️ Backend Development Tasks
Focused strictly on API system design, middleware construction, relational database modeling using embedded SQLite arrays, and RESTful routing infrastructures.

* **Task 1: [Event Registration System](./CodeAlpha_Backend_Development_Tasks/CodeAlpha_Event_registration_system)** — A Node/Express JWT authentication engine integrated intimately with a React-Tailwind user portal layout. Contains robust user/admin role-casting logic.
* **Task 2: [Spice Route Restaurant RMS](./CodeAlpha_Backend_Development_Tasks/CodeAlpha_Restaurant_Management_System)** — A complete multi-table database environment managing concurrent reservations, stock orders, daily sales statistics natively on a Swiggy-inspired frontend map.
* **Task 3: [Custom URL Shortener](./CodeAlpha_Backend_Development_Tasks/CodeAlpha_URL_shortner)** — A lean data redirection REST-API utilizing deterministic ID strings for automatic browser-grade endpoint interception. 

> Note: All backend systems are configured with automated setup scripts (`.bat`) allowing zero-touch environments seamlessly on Windows machines.
