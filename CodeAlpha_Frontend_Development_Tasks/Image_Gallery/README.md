# 🎨 Dynamic Image Gallery 
> **CodeAlpha Frontend Development — Task 2**

A premium, dynamic image gallery utilizing Pinterest-style Masonry layout architecture alongside modern web design methodologies such as local storage mapping and live Blob uploads.

---

## 🌟 Overview
Constructed as a modern photography portfolio format, Image Gallery challenges advanced vanilla CSS techniques avoiding framework overhead (No React, No Tailwind). By directly manipulating the active `backdrop-filter` states and column breakpoints, this simple DOM acts like a high-end enterprise gallery asset.

## ✨ Highlighted Features
* **Fluid Masonry Layout Grid:** Column breaks handling dynamic aspect ratios gracefully without hard crop-factors.
* **Live DOM Search:** Instantaneous title indexing algorithm parsing categories dynamically above the grid view.
* **Client-Sided Upload Modal:** Generate secure, local `blob://` paths rendering high-definition files manually into the browser viewport safely.
* **Pro Lightbox Interface:** An entirely isolated, full-screen picture render engine featuring animated close/download routing.
* **Persistent Themes:** High-level CSS variable architecture responding to a static local storage data-tracker for persistent Light/Dark environment configuration.

## 🛠️ Technology Stack
| Technology | Architecture Concept |
|----------|-------------------|
| HTML5      | Modal structures, Upload Forms |
| CSS3      | `backdrop-filter`, Custom Variables, Grid/Column Algorithms |
| JavaScript (Vanilla)| `localStorage`, Input Debouncing, File Object Mapping |

## 🚀 Quick Start Setup
Zero server build steps or dependency tracking arrays are required. Simply unpack and run physically within the browser!

1. Using your native file explorer, locate the `Image_Gallery` directory structure.
2. Direct your default web browser to intercept `index.html` simply by opening the document directly.
