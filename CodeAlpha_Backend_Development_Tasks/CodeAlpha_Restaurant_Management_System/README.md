# 🍽️ Spice Route — Restaurant Management System
> **CodeAlpha Backend Development — Task 2**

A fully responsive, complete Restaurant Management System coupling a comprehensive Express.js backend API architecture against a robust "Swiggy-inspired" Vanilla JS/CSS client layout.

---

## 🌟 Overview
Engineered to map strict relational table algorithms managing concurrent order volumes seamlessly integrated natively into live inventory management routing nodes simulating modern high-volume restaurant operational procedures.

## ✨ Highlighted Features
* **Complete CRUD Matrixing:** Explicit Admin API keys authorizing total control mapping modification variables onto precise REST endpoints.
* **Multi-Category Filtration Grids:** Real-time dietary classification loops routing user selection variables (e.g. strict Veg/Non-Veg indexing parameters).
* **State Preserved Order Elements:** Tracking arrays actively processing `localStorage` carts safely resolving against dynamic database table stock updates directly upon submission!
* **Daily Metric Integrations:** Instant statistical read-out algorithms providing aggregated order revenues and low stock triggers accurately via nested SQL parameters.

## 🔌 Main System Route Endpoints

### 📦 Administrative Integrations 
`POST /api/menu` — Construct localized objects extracting variables across Multer formatting nodes.
`PATCH /api/inventory/:id` — Synchronize stock matrices maintaining accurate local state tables.

### 💳 Public Array Targets
`POST /api/orders` — Construct sequential order arrays deducting matching variables from static inventory limits immediately.
`GET /api/tables/availability` — Resolve isolated scheduling objects preventing timing conflicts entirely.
